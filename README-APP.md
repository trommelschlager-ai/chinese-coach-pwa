# 我的中文老师 — Мой китайский
Учебное PWA-приложение для мобильного телефона. Пять последовательных уроков китайского с теорией, карточками, диалогами, тестами и локальным прогрессом.

## Установка
1. Опубликуйте ветку `main` из папки `/` в GitHub Pages (Settings → Pages → Deploy from a branch).
2. Откройте https://trommelschlager-ai.github.io/chinese-coach-pwa/ на Android в Chrome.
3. Когда приложение покажет «Уроки сохранены», используйте меню ⋮ → «Установить приложение».
4. Проверьте уроки в режиме полёта.

## Ограничения
- AI-разговор открывает ChatGPT отдельно и требует интернет.
- Озвучивание слов уроков зависит от китайского голосового пакета на телефоне. Новый тренажёр аудирования потоково воспроизводит четыре записи реальных носителей с Wikimedia Commons (нужен интернет); без сети использует установленный системный китайский голос, если доступен. Записи носителей не включены в офлайн-кэш. Авторы и лицензии доступны в приложении.
- Проверка тонов основана на высоте голоса и не заменяет оценку преподавателя.
- Прогресс хранится локально в браузере, поэтому резервное копирование рекомендуется перед очисткой данных приложения.

## Озвучивание: настройка голоса
В разделе «Произношение» есть раскрывающийся пункт «Голос китайского — выбрать и настроить». Он перечисляет только те китайские голоса, которые реально предоставляет устройство, сохраняет выбор и скорость; отдельная кнопка позволяет прослушать пример. Если установлен только один системный голос, переключение невозможно без установки другого. Записи носителей в упражнении «Какой тон ты услышал?» остаются отдельным инструментом, а словарь и диалоги используют выбранный голос устройства.

Открыть упражнение без вступительной обложки: `https://trommelschlager-ai.github.io/chinese-coach-pwa/?start=listening`.

## Произношение — стартовый экран v41
Экран «Произношение» показывает три понятных направления: слушать четыре тона, угадать тон на слух (8 вопросов), произнести слог и сравнить интонацию. Старые упражнения, изображения и микрофон сохранены; они открываются по выбору, не занимая место на стартовом экране. «Голос и скорость · образцы» раскрывает прежние системные настройки и демонстрацию двух голосов реальных носителей (женский 麻 má, Yue Tan, CC BY-SA 3.0 US; мужской 马 mǎ, Wei Gao и Vion Nicolas, CC BY 2.0 FR), с указанием источников. Пока пользователь не оценит качество образцов, системная озвучка слов и диалогов остаётся неизменной. Нет утверждения, что эти две короткие записи могут автоматически озвучить весь курс.
