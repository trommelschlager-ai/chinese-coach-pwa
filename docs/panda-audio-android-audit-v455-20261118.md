## Android-тестирование

Ранее восемь групп Android QA падали преимущественно из-за устаревших фиксированных версий script URL в тестах (v445/v447/v4361). В тестах v455 заменены проверки старых номеров на чтение реальных ссылок из страницы и офлайн-пакета; поведение диалогов, памяти, микрофона и проверка MP3 сохранены. В новом CI добавлена установка `npm ci`, необходимая для существующей `jsdom`-фикстуры.

Полный тестовый прогон исправленной ветки: https://github.com/trommelschlager-ai/chinese-coach-pwa/actions/runs/44216002830 — success. Он проверяет микрофон, семейные диалоги, Non-Stop, HSK1 календарь, HSK2 bridge, память беседы, 42 MP3 по SHA-256 и автоматическое воспроизведение исправления.

**Что остаётся:** реальный тест Android на сети пользователя (разрешения Chrome, воспроизведение в фоне/при заблокированном экране, задержка ответа) и отдельный слуховой контроль тонов. Тесты с `jsdom` не заменяют проверку настоящего микрофона и динамика смартфона.
