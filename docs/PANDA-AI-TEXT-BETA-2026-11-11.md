# Panda AI — текстовая бета, 11 ноября 2026

Отдельная ветка `feat/panda-ai-text-beta-2026-11-11`. Никакие существующие уроки, озвучки и дизайн не заменены.

## Что реализовано
- `panda-ai.html` — чат HSK 1 с выбором одного из 7 уроков, примерами вопросов и локальной очисткой истории.
- `assets/panda-tone-check.mjs` — отдельный детерминированный тренажёр **написанных** тонов; поддерживает пиньинь с диакритикой и с цифрами, показывает различие словарного/произнесённого 你好.
- `worker/panda-ai/src/index.mjs` — защищённый endpoint `POST /v1/chat` на Cloudflare Workers и OpenAI Responses API.
- Сервер проверяет Origin (это не аутентификация), одноразовый токен Turnstile, ограничение размера сообщений, дневные и поминутные D1-квоты; секрет OpenAI никогда не попадает в браузер.
- Данные разговоров не записываются в D1. В OpenAI запросы идут с `store:false`; пользователь видит предупреждение о передаче текста в AI-сервис.

## Подготовка облачного сервера
Нужны **собственные** аккаунты Cloudflare и OpenAI API с оплатой использования. Подписка ChatGPT не равна доступу к API.

1. В панели Cloudflare создай D1 базу с именем `panda-ai-quota`. Скопируй её `database_id`.
2. Из папки `worker/panda-ai` скопируй `wrangler.toml.example` в `wrangler.toml` и вставь `database_id`. Файл с ID не содержит секретов, но шаблон оставлен отдельно.
3. Установи Wrangler (`npx wrangler`), авторизуйся через `npx wrangler login` и выполни `npx wrangler d1 execute panda-ai-quota --remote --file=./schema.sql`.
4. В Cloudflare Turnstile создай widget для `trommelschlager-ai.github.io`. Получи публичный site key и **приватный** secret.
5. Задай секреты в Worker через `npx wrangler secret put OPENAI_API_KEY`, `npx wrangler secret put TURNSTILE_SECRET` и `npx wrangler secret put IP_HASH_SALT`. Для последнего используй длинную случайную строку. Не пересылай секреты в чат и не записывай их в GitHub.
6. Запусти `npx wrangler deploy`. Проверь `GET https://<твой-worker>.workers.dev/health` из браузера приложения; ожидание: `{"ready":true}`.
7. Только после развёртывания заполни публичные поля `apiBase` и `siteKey` в `assets/panda-ai-config.js`; проверь ответы, лимиты и пользовательские ошибки. Ключ OpenAI в этот файл **никогда** не записывать.
8. Включать кнопку на действующем сайте только после smoke-тестов. Пока эта работа находится лишь в отдельной ветке.

## Правила Panda AI
- HSK1, русский язык, короткий ответ; обязательные 汉字 + пиньинь с тонами + перевод для китайских примеров.
- Исправляет ошибки точно, не соглашается автоматически и задаёт одно закрепляющее упражнение.
- Различает словарный пиньинь и тональные изменения 你好, 不, 一.
- Не заявляет, что услышал ученика: в этой версии микрофон не используется.
- Пользовательский вопрос и история — недоверенные данные. Высший уровень правил определяет сервер, не браузер.

## Лимиты и коммерческий статус
- 4 обращения/мин с одного IP, 30 обращений/сутки с IP, общий максимум 400 в сутки, 450 output tokens на обращение.
- Защита не равна платной авторизации. Для продаж дополнительно нужны аккаунты, контроль оплаченного доступа, аналитика расходов и политика конфиденциальности.
- Квоты учитывают попытки даже при ошибке модели — защита бюджета приоритетнее удобства.
- D1 хранит HMAC-хэши IP (без сырых IP), но для коммерческого использования всё равно нужна правовая проверка обращения с такими данными.
- Желательно ограничить месячный бюджет в OpenAI, настроить alerts и внешние WAF-правила.
- Удаляй старые D1-квоты отдельной плановой задачей; сейчас схема не выполняет автоматическое удаление.
