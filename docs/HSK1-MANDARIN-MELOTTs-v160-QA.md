# HSK 1 — независимый женский голос MeloTTS, v160

## Почему меняем систему

Пользователь сообщил систематическое неправильное произношение женского Kokoro: в слове **妈妈 (māma)** в конце слышался посторонний звук, похожий на «MAMAI». Ранее смена женских тембров Kokoro и корректировка темпа не устранили жалобу.

**Решение:** заменить *движок*, а не тембр: все 123 синтетических женских фразы HSK 1 теперь генерируются **MeloTTS** `ZH` при скорости 1.0, без ускорения, растягивания или изменения высоты тона. Источник — `myshell-ai/MeloTTS`, лицензия MIT.

## Что сохраняем
- 14 реплик мужского персонажа: `zm_yunjian` из ранее существующего набора
- Изолированное **日 (rì)**: отдельная лицензированная человеческая запись Yue Tan
- Человеческие записи задания на распознавание четырёх тонов
- Все 7 уроков, макеты, 7 учебных шагов, задания, прогресс пользователей и обратная совместимость

## Результат генерации
- `assets/hsk1-voices-v160/manifest.json` — ровно **123 MP3**, формат mono MP3, проверка длительности
- `assets/hsk1-voices-map-v160.js` — 123 новых женских + 14 старых мужских + 1 оригинальная запись 日
- Примеры для проверки на слух: **妈妈 māma**, **你好 nǐ hǎo**, **汉字 hànzì**, **拼音 pīnyīn**, **声调 shēngdiào**, а также предложения из раздела «Семья»
- Версионирование service worker: **v160**; не подставлять старые закэшированные женские клипы

## Необходимые QA
- `npm run check` и `npm run check:release`, включая точную карту 138 аудиомаршрутов и соответствие полов персонажей
- Визуальная QA на 360/390/412 px, работоспособность кнопок аудио и переходов
- **Отдельно прослушать** 妈妈 и остальные чувствительные китайские слова: техническая проверка MP3 не доказывает правильности фонетики
- Не заявлять полную проверку тонов и не начинать платный запуск без независимой проверки носителем китайского

Пользователь потребовал заменить именно голос; выбран другой движок. Прежние файлы не удалены из истории Git, чтобы возможен был откат без потери уроков.
