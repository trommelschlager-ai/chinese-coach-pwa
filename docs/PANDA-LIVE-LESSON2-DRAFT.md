# Разговор 2 — Кто ты?

Готовность: сценарий и проверка ответов реализованы; три MP3 отсутствуют. Это черновик, его нельзя выдавать за готовый озвученный урок. Публикуемый первый разговор не меняется, пока эта ветка не объединена с main.

Предпросмотр разработчика: `panda-voice-pilot.html?lesson=2&preview=1`. Обычная ссылка `?lesson=2` не открывает незавершённую практику. Первый разговор открывается без параметров. Панда, анимации и рисунок не изменены.

| Кто | Реплика | Пиньинь | Перевод |
|---|---|---|---|
| Панда | 你好！ | Nǐ hǎo! | Привет! |
| Ученик | 你好！ | Nǐ hǎo! | Привет! |
| Панда | 你是老师吗？ | Nǐ shì lǎoshī ma? | Ты учитель? |
| Ученик — вариант 1 | 我是老师。 | Wǒ shì lǎoshī. | Я учитель. |
| Панда — ответ 1 | 我也是老师。 | Wǒ yě shì lǎoshī. | Я тоже учитель. |
| Ученик — вариант 2 | 不是，我是学生。 | Bú shì, wǒ shì xuésheng. | Нет, я ученик. |
| Панда — ответ 2 | 我是老师。 | Wǒ shì lǎoshī. | Я учитель. |

Допускаются также полное отрицание «我不是老师，我是学生» и краткое «我是学生». На вопрос о профессии не принимаются «你好», «我很好», незавершённые предложения или вопрос вместо ответа. 的 в 是的 не вводится неявно. 也 уже объяснялось в первом разговоре. Перед практикой доступны значения 老师、学生、是、不是、也; произношение 不 перед четвёртым тоном объясняется как bú.

## Озвучка

Приветствие повторно используется из пользовательской записи Luvvoice, уже применённой в первом разговоре. Для продолжения нужны три полные фразы, тем же голосом, скоростью и настройками:

```text
你是老师吗？

我也是老师。

我是老师。
```

Голос нельзя подменять существующими записями другого происхождения. Точное имя голоса в последнем присланном MP3 не было указано. Нужна та же выбранная пользователем настройка генератора, а не предположение об имени голоса. Файл можно прислать одним MP3; фразы будут разделены по паузам.

## Реализация и проверка

- Общая проверка ответов принимает набор реплик выбранного разговора; совместимый verifyPilotAnswer сохраняет первый сценарий.
- Ветки teacher / student выбраны по точному нормализованному ответу, без платного API.
- Черновик доступен только через явный preview-параметр. Темы 3–7 остаются пустыми недоступными черновиками.
- Отдельный ключ прогресса урока 2 не перезаписывает первый разговор.
- При отсутствии MP3 нет кнопки воспроизведения, показано сообщение о недоступной записи; ложная речь не запускается.
- `node --test tests/panda-voice-pilot.test.mjs tests/panda-live-lesson2.test.mjs`: 5 тестов PASS. Проверены обе роли, отрицание, неподходящие ответы, изоляция прогресса, закрытый обычный URL и отсутствие ложной озвучки.
- Физический Android и правильность произнесённых тонов этим тестированием не подтверждены.

Чтобы включить второй разговор после получения MP3: проверить все три текста, добавить полные записи в карту аудио и огибающие громкости, повторить браузерный тест обеих ветвей, затем снять статус draft и добавить вход в практику. До этого не изменять опубликованный курс ради доступа к черновику.
