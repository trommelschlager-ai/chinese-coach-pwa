## Stage 1 extension — modal actions and dialogue context
Added pure interpreters for time + action + 想/要/打算/会 with negation, yes/no and open questions, and reciprocal 你呢. 会 remains explicitly ambiguous (ability/future), never invent intent. Contextual agreement binds to a supplied nonnegative yes/no question, repetition preserves exact last Panda utterance, meaning requests are separate from repetition, reciprocal questions refer only to a supplied recognized learner action. Caller must clear stale context and own reply generation. Unknown or incomplete inputs return null or request clarification. Direct JS assertions: 10 explicit action examples, 576 combinations, 9 reject cases, 9 context tests. Combinations test parser behavior, not human-rated language quality; no live integration or audio claims. Keep isolated until release candidate is stable.
