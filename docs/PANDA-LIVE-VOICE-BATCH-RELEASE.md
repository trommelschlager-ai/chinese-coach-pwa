# Panda Go Live — подключение 14 реплик и семи разговоров

В пользовательской записи `luvvoice.com-20261111-leFTmr.mp3` (28.704 с, 24 kHz mono, 48 kbps) найдены все 14 фраз подготовленного списка. Все они разделены на полные реплики с запасом примерно 130 мс перед речью и 230 мс после неё. Исходный файл сохранён без перекодирования. Пик исходника −4.5 dBFS, средняя громкость −20.2 dBFS; перегрузки сигнала нет.

## Доступные темы

1. Приветствие и самочувствие — ранее озвученный разговор.
2. Учитель / ученик — обе ветви ответа.
3. Возраст — любой возраст 1–100, цифрами или иероглифами.
4. Дни недели — условная ситуация «сегодня понедельник» явно написана на экране.
5. Даты — условная дата 5 марта явно написана на экране.
6. Семья — есть / нет старшего брата, в том числе с количеством.
7. Погода — сегодня и завтра, три реплики ученика с отдельным прогрессом.

Темы выбираются в одном компактном списке вверху разговорной страницы. Все реплики Панды имеют точные полные аудиофайлы; очередь недостающих фраз пуста. Тестовая маркировка сохранена. Карта курса, главная страница, утверждённые учебные экраны 1–7 и старые записи не изменялись. Доступ автоматически после завершения каждого основного урока пока не подключён: все темы открыты на отдельной тестовой разговорной странице. requiresLesson сохраняет связь с уроком для последующей интеграции.

## Проверка текста и её пределы

Локальная модель faster-whisper base распознала всю запись в контексте точно по списку из 14 предложений, без подсказки ожидаемого текста. На отдельных коротких фрагментах tiny и base делали ошибки, например в «我三岁» и «我有一个哥哥». Эти одиночные результаты не объявлены оценкой качества голоса: полный контекст распознан правильно, границы фрагментов сверены по паузам, окончания не вырезаны. Raw-результаты обоих способов сохранены в `assets/panda-live-voice-v3/verification.json`.

Это проверка соответствия текста и нарезки. Полная ручная проверка тонов и акустики не выполнена. Приложение по-прежнему проверяет распознанный текст ученика, а не правильность произнесённых тонов. Настоящий микрофон Android в этой среде не проверен.

## Файлы и проверки

- `assets/panda-live-voice-v3/p01.mp3`–`p14.mp3`: новые полные реплики.
- `source-original.mp3`, `manifest.json`: оригинал, границы, длительности и SHA-256.
- 19 фраз в общей карте: 14 новых, 4 из предыдущей записи и выделенное из неё «谢谢».
- Для всех 19 файлов есть RMS-огибающие с шагом 25 мс; движения рта используют реальное время проигрывания.
- Версии импортов обновлены до live5 для защиты от старого кэша .mjs.
- Все 9 локальных тестов PASS. Проверены нормальные URL тем, отсутствие пропусков аудио, хеши новых файлов, длительность огибающих, варианты ответов и отдельный прогресс.
- Chrome локально: выбор темы, воспроизведение новых вопросов и ответов, возраст, отрицательная ветвь семьи и три шага погоды проверены.
- CI дополнен мобильными сценариями всех семи тем, обеими ветвями представления/семьи, проверкой воспроизведения каждой используемой реплики и загрузкой всех 19 MP3. Реальные события распознавания в CI имитируются.

Ни генерация речи при каждом сообщении, ни платный AI API не подключались: плеер использует локальные MP3. Встроенное распознавание речи браузера может требовать интернет; это не офлайн-гарантия.
