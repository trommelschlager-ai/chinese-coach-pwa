Полное завершение аудио заблокировано отсутствующими записями.

Из 25 элементов доступны три цельные записи присланной китаянки. Для единого голоса этой женщины нужны ещё 22. Предыдущий список из 18 учитывал семь готовых элементов другого голоса Yue Tan. Его нельзя использовать как полный список для перехода на присланный голос.

Две целые фразы 今天星期五。 и 今天是星期五。 были пропущены при предыдущем поиске. Это исправлено в инвентаризации. Сами найденные записи извлечены без повторного кодирования из существующего разрешённого набора. В работающем уроке голоса не смешаны: эти три файла доступны только здесь для проверки.

Автоматическая расшифровка не подтверждает правильность тонов или отсутствие воспринимаемого шума. Слуховая приёмка носительницей остаётся обязательной.
