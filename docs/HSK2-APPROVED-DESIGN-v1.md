# Panda Go — HSK 2 · утверждённый светлый дизайн и первый рабочий модуль

Дата: 13 ноября 2026. Ветка: hsk2-foundation-2026-11-13-v1 (черновик).

## Утверждённое владельцем направление

- Светлая розово-сиреневая гамма, озеро, пагода, сакура, золотые тонкие рамки, мягкое фиолетовое свечение.
- В основе три присланных владельцем светлых референса. Панда с книгой и пейзаж используются как компактная иллюстрация в верхней части; большие изображения не должны вытеснять слова и задания.
- Вместо надписей «День 1–5» — учебные шаги, которые можно проходить в своём темпе и повторять.
- Последовательность: краткое повторение HSK 1 → знакомство со словами → проверка → одно правило → примеры → конструктор → учебный диалог.
- Большие бытовые темы и сложные конструкции появляются только после основы.

## Реализация

- hsk2-start.html — новый интерактивный самостоятельный модуль с утверждённой светлой палитрой и компактным верхним баннером.
- hsk2-map.html → hsk2-start.html#map; hsk2-lesson1.html → hsk2-start.html#lesson (совместимые ссылки).
- Одобренный пейзаж и Панда встроены внутрь файла в формате WebP data URI, чтобы превью можно было открыть отдельно. Все задания и тексты — настоящий HTML, а не изображение.
- На карте семь больших разделов; только первый прототип действительно открыт, остальные шесть обозначены «СКОРО».
- Повторение HSK 1: девять экранов (20 слов и частиц по пяти группам, три примера, два вопроса, итог), без утверждения, что это полный словарь HSK 1.
- Первый микроурок HSK 2: десять экранов — 中文 Zhōngwén, 学习 xuéxí, 忙 máng, 很 hěn, два вопроса на запоминание, два правила, три примера, конструктор предложения, контрольный перевод, диалог из четырёх реплик и итог.
- Пиньинь с тоновыми знаками и перевод, скрытие пиньиня, объяснение неправильного ответа, возможность повторить, независимый от HSK 1 localStorage ключ pg-hsk2-approved-v1-state.
- Отдельный экран прогресса; нет принудительных календарных дней.

## Проведённая проверка

- Скрипт страницы проходит проверку синтаксиса Node.
- В Chromium пройдены карта → девять экранов повторения → десять экранов микроурока → конструктор → диалог → завершение → прогресс, на 360×640, 384×850 и 412×915 px, без ошибок JS.
- В коротких окнах допускается аккуратная внутренняя прокрутка ради читаемости.
- Никаких правок HSK 1, Panda AI, кэша или платежей в main.
