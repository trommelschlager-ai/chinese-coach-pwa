# Пакетная загрузка аудио Panda Street

Запустите импорт из корня репозитория в рабочей ветке. Нужны Python 3,
FFmpeg и ffprobe. Каждый ZIP содержит отдельные MP3 и `manifest.json` в корне.
В манифесте у каждой реплики есть `file`, `expected_text`, `start`, `end`
и, при наличии, `status`. Передайте оригиналы в порядке записи. Таймкоды
относятся к началу своего оригинала, при переходе к новому исходнику отсчёт
начинается заново. Укажите `--role female` для пакета женского голоса.

```sh
python3 scripts/import-panda-street-audio.py \
  --batch lesson3-20261127 --lesson 3 \
  /path/to/street_lesson3_27_review.zip \
  /path/to/luvvoice.com-20261127-5UUA1M.mp3 \
  /path/to/luvvoice.com-20261127-mtXX0r.mp3 \
  /path/to/luvvoice.com-20261127-iON8eo.mp3
python3 scripts/import-panda-street-audio.py --check
```

Перед импортом сверьте китайский текст с исходной записью. Импорт проверяет
ZIP, декодирование MP3 и длительность, сохраняет SHA-256, исходник и таймкод
каждого клипа и переносит статус исходного манифеста. Нативная проверка тонов
пакета урока 3 в манифесте не отмечена.

Уроки и разговорный режим ищут клипы в
`assets/panda-street-voice-v20261125.js` по реплике и голосу. Повторное
использование реплики не требует нового MP3. Импорт использует имеющийся
файл при совпадении SHA-256 и останавливается при попытке назначить другой
файл уже зарегистрированной реплике того же голоса. Повтор того же пакета
с теми же входными файлами безопасен.

Зафиксируйте изменившийся реестр, новые клипы в `assets/panda-street-audio/`
и оригиналы в `audio-source/panda-street/` одним коммитом. Отправьте ветку в
GitHub и откройте pull request в `main`. После проверок объедините его и
проверьте воспроизведение на GitHub Pages.
