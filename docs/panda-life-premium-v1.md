# PANDA LIFE pilot
Two existing course-based scenarios (lesson 1 introduction, lesson 8 shopping), each with three prompts and verified repository MP3 paths. Lesson numbers refer to the current HSK2 numbering. No claim of listening quality or actual speech evaluation; match only curated text and never penalize unknown responses or recognition failure. Free dialogue and UI integration are not implemented. Existing cafe preview duplicates shopping content, so cafe needs independent content before adding it. Keep approved design untouched. Run from repository root: node --test tests/panda-life-premium-v1.test.mjs.
