# HSK1: единый розовый стандарт кнопок, v437

## Изменения

Источник цвета, градиента и исходной тени — `.primary` урока 5 из `assets/panda-go-approved-lessons-v231.css`. Источник движения — существующее нажатие `translate: 0 2px`, `brightness(.9)`, переход 100 мс. Общая реализация дополняет его мягкой внутренней тенью и короткой обратной связью после отпускания.

Один CSS-компонент используется во всех семи уроках. Ширина, высота, расположение, тексты и обработчики учебных заданий сохранены. Небольшие аудиокнопки круглые. Правильные/неправильные состояния и сообщения сохранены; отключённые кнопки приглушены. Удалено подключение старого скрипта окраски кнопок уроков 1–4. Общий обработчик поддерживает короткое/длительное нажатие, отпускание вне элемента, отмену указателя, прокрутку, клавиатуру, уход страницы в фон и защиту от повторного клика в течение 280 мс.

Карта использует прежний PNG без изменения байтов. Фон SVG имеет вырезы, а 12 поверхностей (7 уроков, 3 нижних действия и 2 верхних действия) показывают соответствующие исходные пиксели отдельно. При нажатии движется весь элемент вместе с номером, текстом и значком прогресса. Неподвижной копии внутри выреза нет. Цвета карточек и нижних кнопок сохранены. Прежние белые/дублированные наложения и накопленные конфликтующие правила удалены.

Встроенный в урок 1 тренажёр получает тот же компонент только в режиме `embedded=1`. Самостоятельная страница тренажёра сохраняет своё оформление. В список офлайн-загрузки добавлены три новых общих ресурса. Имена ресурсов и параметры `v=437` новые; существующий service worker уже использует network-first для HTML/CSS/JS.

## Замечания и границы проверки

В уроке 3 существующий текстовый счётчик «Прослушано» обновляется при перерисовке, хотя класс `heard`, сохранённые отметки и разблокировка «Дальше» срабатывают после окончания MP3. Это обнаруженная особенность исходного учебного скрипта; в задаче только по кнопкам он не менялся.

Не выполнены: проверка на физическом Android, установка/перезапуск мобильного PWA, реальная запись с микрофона и распознавание живой речи. Все задания всех экранов до финального прохождения семи уроков не проходились. Эти ограничения нельзя считать проверенными по наличию CSS.
