# Panda AI v304 — безопасное знакомство с HSK 2

Дата: 13 ноября 2026. PR #75. Основной HSK 1 и утверждённые голоса/экран без переработки.

## Что активируется в существующем чате
Переходный мини-набор из первого утверждённого микроурока HSK 2:

| Слово | Пиньинь | Значение |
|---|---|---|
| 中文 | Zhōngwén | китайский язык |
| 学习 | xuéxí | изучать, учиться |
| 忙 | máng | занятый |
| 很 | hěn | часто используется перед прилагательным; не всегда сильное «очень» |

Это **вводная** база, не 36 предварительных слов будущего оплачиваемого курса. На новой схеме HSK 3.0 часть материала относится к базовому уровню; здесь он нужен как мост между уровнями.

Поддерживается в **Non-Stop** на существующем экране Панды:
- `HSK 2` — сообщение о вводной практике;
- `中文是什么意思？`, `学习怎么读？`, «Что значит 很?» — смысл, пиньинь, учебные примеры;
- `用忙造句`, «Составь предложение с 学习» — утверждённый образец;
- `我学习中文。`, `你学习中文吗？`, `你忙吗？`, `我很忙。`, `我不忙。` — короткие разговоры и встречные вопросы;
- `我是忙` — исправление на `我很忙`.

**Тоны:** 中文 zhōngwén — 1+2; 学习 xuéxí — 2+2; 忙 máng — 2; 很 hěn — 3. В речи `我很忙` стандартно `Wǒ hěn máng`. Текстовый ответ Панды не оценивает акустически тоны ученика.

## Границы и коммерческая безопасность
- `assets/panda-hsk2-seed-v303.json` содержит 7 направлений и 36 **предварительных** кандидатов уровня 2 плюс 4 переходных слова. Файл не импортируется ни в `panda-live-dialogue`, ни в `panda-live-screen`, ни в экран HSK 1.
- Неподтверждённые 36 слов не открыты через разговорный движок: запросы вроде `爱好是什么意思` остаются вне учебного покрытия HSK 1.
- Локальная проверка JavaScript **не является защитой оплаченного доступа**. Для коммерческого HSK 2 потребуется серверная проверка прав и/или отдельная архитектура доставки контента. Публичный репозиторий не подходит для хранения секретного оплачиваемого материала.
- Новые фразы не получают выдуманный MP3 или системную замену утверждённого голоса. `audioKey:null` для новых фраз; существующий клип `很好` переиспользуется без изменения.
- Свободной генеративной модели и офлайн-ASR здесь нет.
- Переходные вопросы доступны без HSK 2 оплаты, полноценный курс не включён.

## Техника
- `assets/panda-hsk2-bridge-v304.mjs` — отдельный простой локальный движок ввода/практики.
- `assets/panda-live-dialogue-v272.mjs` — минимальное подключение до старой лексической ветви, не затрагивает HSK 1.
- `panda-voice-pilot.html`, `assets/panda-live-screen-v270.mjs`, `assets/panda-hsk1-questions-v281.mjs` — версия v304 для корректной загрузки.
- `sw.js`, `assets/offline-pack.json` — версия офлайн-кэша 304 и необходимые URL; старые записи голоса без изменений.
- `scripts/verify-panda-hsk2-bridge-v304.cjs`, QA GitHub Actions и мобильный Chromium.

## Критерии выпуска
Запустить `node scripts/verify-panda-hsk2-seed-v303.cjs` и `node scripts/verify-panda-hsk2-bridge-v304.cjs`, полный `Chinese course QA`, `Panda Android voice pilot QA`. Проверить вводы на реальном Android в режиме с интернетом и без него после загрузки офлайн-пакета.

Дизайн HSK 2 находится в **отдельном** draft PR #74; PR #75 не изменяет его.
