# Panda Go — общая и личная память (этап 1 · 23 ноября 2026)

**Статус:** отдельный тестовый экран; основной разговорный AI не изменён. Облачный AI и платная озвучка не подключены.

## Два самостоятельных уровня хранения

1. **Общая библиотека** (отдельная база IndexedDB `panda-go-shared-library-v1`) — одинаковые для всех учеников проверенные учебные фразы HSK1–2 с пиньинем, русским переводом и заранее опубликованным MP3 Xiaoxiao. Материалы опубликованы владельцем в GitHub Pages, но **каждый ученик самостоятельно скачивает копию на своё устройство**. Удаление/обновление общей библиотеки **не должно затрагивать** личные фразы. Это не единая удалённая память работающей модели.
2. **Личная библиотека** (существующая база `panda-go-memory-v1`) — выбранные пользователем фразы и MP3, сохраняемые локально только по согласию. Данные не выгружаются на GitHub и не публикуются. В текущем тестовом экране ещё нет полноценного облачного резервирования персональной памяти.

## Управление общим выпуском

- Достоверный исходник общей библиотеки: `assets/panda-shared-library/manifest-v1.json`.
- Первый выпуск `release: 1` содержит 3 ранее утверждённых диалога. Для каждого указаны тема, HSK, входная фраза, ответ, пиньинь, русский перевод, файл MP3 и запись редакторского утверждения.
- Модуль `assets/panda-shared-library-v1.mjs` проверяет, что **каждая** запись в манифесте имеет **точное совпадение** с утверждённой записью `assets/panda-memory-reviewed-samples-v1.mjs`. Таким образом, случайные ответы облачной модели и персональные реплики не могут попасть в общую библиотеку через подмену JSON. Обновление каталога требует отдельной проверки и выпуска изменений в GitHub.
- Обновление доступно нажатием `Скачать / обновить общую память`; для скачивания нужна сеть. Повторная установка той же версии не загружает MP3 повторно. Если хотя бы один MP3 не скачан, новая версия не записывается частично.
- Заранее сохранённые фразы могут воспроизводиться без интернета. Для свежего контента по-прежнему нужны онлайн-доступ и подтверждение прав использования аудио.
- Кратковременные URL Luvvoice не публикуем как офлайн-ресурсы; внутри базы сохраняем реальные проверенные MP3-файлы с собственного GitHub Pages.

## Android — как проверить

1. Открой `https://trommelschlager-ai.github.io/chinese-coach-pwa/panda-shared-memory.html` с интернетом.
2. Нажми **Скачать / обновить общую память**. Убедись, что указаны **версия №1, 3 фразы**.
3. Нажми **Подготовить офлайн** для сохранения страницы и кода в Cache Storage.
4. Включи авиарежим. Попроси общую память ответить на `你为什么喜欢喜剧片？`. Панда должна показать `因为喜剧片很好笑。`, пиньинь и русский перевод; кнопка Xiaoxiao воспроизводит **сохранённый** MP3.
5. По желанию нажми **Удалить скачанный общий набор**: только общий набор исчезнет из телефона; локальная личная память остаётся.

## Важные ограничения

- Общая библиотека пока **не подключена к главной Panda AI**. Это отдельно опубликованный лабораторный экран.
- **Нет** автоматической публикации всех фраз учеников: общий выпуск изменяется только после ручной/редакторской проверки; личные разговоры не переходят туда автоматически.
- Офлайн сопоставляет **известные входные предложения** с темами, без свободного локального AI и без офлайн-микрофона.
- Установка на устройствах зависит от квот IndexedDB и Cache Storage. Очистка данных сайта может удалить обе базы. Резервирование, серверная синхронизация персональной памяти, управление аккаунтами и контроль многопользовательского доступа — отдельная задача.
- В текущей версии ограничение на один выпуск — **100 проверенных записей**; для тысяч выражений нужны тематические пакеты с отдельными версиями, управление свободным местом, пакетное скачивание и система отзыва некачественных карточек.
- Проверка манифеста является **редакторским allowlist в коде**, а не криптографической подписью; для коммерческого распространения нужна дополнительная защита цепочки публикации и проверка лицензий MP3.
- Никакие личные данные ученика не должны попадать в общедоступные файлы GitHub.

## Проверка

- `node --test tests/panda-shared-library-v1.test.mjs` проверяет, что чужие/неутверждённые фразы, поддельные голоса, поля студента и повреждённые релизы отклоняются.
- `node scripts/qa-panda-shared-library-browser-v1.mjs` выполняет браузерный тест на мобильном размере 393×852: скачивание трёх настоящих MP3, повторная установка без лишнего аудио-трафика, открытие страницы и озвучка офлайн, удаление общей базы без изменения личной.

**Рекомендованный следующий шаг:** после проверки на реальном Android дать владельцу редакторский интерфейс пополнения общего каталога, а затем независимую синхронизацию личных фраз по авторизованному аккаунту с шифрованием и явным согласием. Никаких непроверенных AI-ответов в общий курс автоматически.
