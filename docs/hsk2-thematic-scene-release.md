- Готово 10 полных вертикальных 3D-постеров, каждый исходно **843×1866**.
- Экспортированы `lesson-01-full.webp` — `lesson-10-full.webp` в WebP quality 93 и архив `Panda_Go_HSK2_Full_Covers_PR177.zip` (содержит все 10 WebP + `scenes-manifest.json`).
- В GitHub PR №177 обновлены скрипт подключения, CSS и manifest с реальными SHA256 для этих 10 файлов.
- Код предпочитает цельный полноэкранный постер. Если WebP отсутствует, оставляет исходную рабочую обложку.
- В новой обложке «Назад» отрисован поверх постера как доступная кликабельная кнопка, потому что в новых изображениях нарисованной кнопки нет.
- Проверено программно: 10/10 WebP декодируются, имеют размер 843×1866 и совпадают с SHA256 в manifest.
- Математически отношение сторон 843/1866≈0.45177. На 360×800, 393×873, 412×915 с `object-fit:cover` требуется лишь крошечная обрезка края, а не масштабирование по разным осям.
- Локально получены три **статических** изображения-превью этих размеров. Это **не** браузерное/Android-тестирование.

## Блокер для выпуска
**10 бинарных WebP ещё не загружены в GitHub**, потому что действующий GitHub connector в этом окружении умеет записывать текст и Git blobs с переданным base64, но не принимает готовые файлы из контейнера напрямую. Не путать с отдельно подготовленным архивом `Panda_Go_HSK2_10_thematic_scenes.zip` со старой компоновкой: нужен только `Panda_Go_HSK2_Full_Covers_PR177.zip`.

Сначала распаковать этот ZIP и загрузить `assets/hsk2-approved-covers/lesson-XX-full.webp` (10 файлов) **именно в ветку** `hsk2-thematic-bottom-scenes-20261123` PR №177. Обновлённый manifest уже находится в ветке и совпадает с архивом.

## Что проверить после загрузки
1. Успех `python tests/hsk2-thematic-scene-check.py` и GitHub Actions.
2. Десять отдельных реальных страниц в Chrome Android при 360×800, 393×873 и 412×915. Не использовать для валидации коллаж или просмотрщик галереи.
3. Видимая и рабочая кнопка «Назад», 6 учебных плиток и «Начать урок» на каждой странице.
4. Верх и низ заполнены без полос, ни одно лицо/кнопка не обрезаны, нет искажения и лишней прокрутки.
5. Озвучка, тесты, микрофон, прогресс, блокировки — не должны измениться.
6. **Сверить визуальный текст** по темам (русский, китайский, pinyin), особенно отсутствие опечаток генерированных изображений.

Не сливать PR №177 в main до полной проверки. Предыдущая попытка Playwright в текущем окружении была заблокирована политикой браузера (включая доступ к localhost), поэтому успешную проверку реальных страниц и кнопок заявлять нельзя.
