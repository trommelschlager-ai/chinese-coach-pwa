**Уникальных слов и выражений: 80.** Повторяются по двум урокам `我`, `是`, `学生`, `你`, `日`, `今天`. Повторы сохраняют свои исходные уроки. У каждой уникальной единицы есть исходный пиньинь, русский перевод, 1 из 21 грамматической категории и проверенный учебный пример. Ряд единиц (`口`, `木`, `日`, `零`, `它`) изучается сначала как отдельный иероглиф/слово; они **не выдаются за полноценные предложения**.

**Существующий звук:** 75 уникальных слов имеют путь к уже подключённому аудиофайлу в `panda-live-audio.mjs` или `panda-hsk1-voice-v280.mjs`. Для пяти исходных единиц отдельного файла нет: `人`, `口`, `木`, `他们`, `百`. Не создаём поддельный аудиоклип, не склеиваем слова, не используем новый голос.

## Тоны и грамматика: отдельные проверки

| Слово | Словарный пиньинь | Замечание |
| --- | --- | --- |
| `你好` | `nǐ hǎo` | В связной речи первый третий тон обычно реализуется вторым: `ní hǎo` |
| `一个` | `yí ge` | `一` перед четвёртым тоном `个` меняется; `个` произносится нейтрально |
| `一` | `yī` | Базовый тон первый; в `一百` употребляется `yì`, отдельные названия месяцев имеют свою норму |
| `不是` | `bú shì` | `不` меняет тон перед четвёртым тоном |
| `学生` | `xuésheng` | `sheng` нейтральный |
| `妈妈` | `māma` | Второй слог нейтральный |
| `吗` | `ma` | Нейтральный тон даже без диакритики |
| `我的` | `wǒ de` | `de` нейтральный |

Визуальный пиньинь берётся из исходных уроков; браузерное распознавание речи не является акустической проверкой тонов. На этапе v302 аудиоанализ тонов не добавлен.

## Архитектура новой системы

- `assets/panda-brain-hsk1-v302.mjs`: словарь по данным уроков с категориями, примерами, тонами; анализ специальных учебных запросов; ограниченный анализ грамматических конструкций.
- `assets/panda-live-dialogue-v272.mjs`: подключение словаря, проверка доступа к урокам и продолжение разговора по теме; старые проверенные вопросные ответы остаются приоритетными.
- `assets/panda-curriculum-tutor.mjs`: существующий раздел объяснения урока может показывать расширенное объяснение слова без новой страницы.
- `assets/panda-live-screen-v270.mjs`: краткий диалог принимает словарные объяснения, остальные интерфейсные элементы и обработка микрофона оставлены на прежних местах.
- `panda-voice-pilot.html`: версия v302, новая ссылка на модуль.
- `sw.js`, `assets/offline-pack.json`: обновлённый номер кэша и пути к v302.
- `scripts/verify-panda-brain-v302.cjs`: регрессионные проверки всех 80 слов, 86 записей, примеров, тонов, ограничений доступа, запросов на китайском и русском, конструкций предложений и воспроизведения.

### Поддерживаемые виды запроса

- `妹妹是什么意思？` — значение, пиньинь, категория и пример из урока.
- `一个怎么读？` — тон и описание изменения `一`.
- `用春天造句` — заранее проверенный учебный пример с переводом.
- «Какие тоны у 学生?» — возвращает исходный правильный пиньинь и примечание о нейтральном тоне.
- «Составь предложение с 老师» — учебный пример по проверенной грамматике.
- `我有两个妹妹`, `我的妈妈是老师`, `他有姐姐`, `今天是晴天` — дополнительные распознаваемые простые конструкции при открытых нужных уроках.

### Границы

Это **локальный, детерминированный словарный интеллект, не генеративная языковая модель**. Он не должен произвольно сочинять факты о людях, прогнозы или дополнительные MP3. Формулировки вне существующего словаря могут не распознаться. Сведения о дате и погоде внутри примеров помечены как учебные. Непройденные темы не раскрываются, ошибки `我不有妹妹` и похожие продолжают исправляться прежней логикой.

## Проверки релиза

1. Проверка каждого из 86 исходных словарных элементов и 80 уникальных единиц.
2. Проверка 21 грамматической категории, 80 примеров и связанных с ними существующих аудиопутей.
3. Тестовые лексические запросы на русском и китайском, составление корректных предложений, отказ для отсутствующих слов и закрытых уроков.
4. Регрессионные тесты v301: 311 ранее поддерживаемых альтернатив вопросов.
5. Общая Chinese course QA и Panda Android voice pilot QA (эмуляция мобильного Chrome).
6. Сборка GitHub Pages; подтверждение статуса проверяется отдельно.

**Нужное следующее развитие:** больше естественных проверенных конструкций, валидация носителем китайского языка сложных примеров, запись пяти отсутствующих отдельных слов тем же утверждённым голосом только с согласия владельца, отдельный акустический тренажёр тонов, затем расширение словаря до HSK 2.
