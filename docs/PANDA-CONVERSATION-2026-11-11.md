# Panda Go — разговорный Panda AI: бета v1 (11 ноября 2026)

**Основная цель:** самостоятельная практика устной речи после изучения урока. Ученик покупает курс один раз, а тренажёр работает без оплачиваемых AI-запросов.

## Что сделано

- `panda-talk.html` — отдельный экран коротких китайских диалогов; `assets/panda-conversation-v1.mjs` — 8 сценариев по 7 урокам; `assets/panda-conversation-ui-v1.mjs` — проверка ответов, подсказки, прогресс по сценарию и кнопка микрофона.
- Сцены открываются после завершения соответствующего урока по существующим ключам прогресса. Исключение: базовый диалог 你好 доступен с начала.
- Для ученика после урока 1 есть дополнительный сценарий «Как дела?». Фразы 你好吗 / 我很好 / 你呢 / 我也很好, 谢谢 сначала представлены с пиньинем и переводом, поскольку **в первом уроке этих фраз ещё нет**.
- Для уроков 3–5 указаны **учебные ситуации**, а не реальные текущие дни или даты.
- Локальная проверка допускает варианты правильных ответов на китайском и пиньинь со знаками/цифрами тонов, не засчитывает смысловые/грамматические ошибки.
- Статус завершения диалога сохраняется отдельно; уроки не отмечаются пройденными автоматически.
- Браузерное распознавание речи включается только по кнопке. Если браузер не поддерживает его, остаётся текстовый ответ. Распознанные слова ученик проверяет и подтверждает перед отправкой.
- Никаких запросов к OpenAI, платному backend или хранилищу аудио нет.

## Ключевое ограничение для коммерческой версии

Текущее сопоставление транскрипта **НЕ оценивает китайские тоны по голосу**: браузер может корректно транскрибировать слово, даже если ученик произнёс неправильный тон. Заявлять обратное нельзя.

Браузерный SpeechRecognition может работать через внешнюю инфраструктуру браузера, может требовать интернет и недоступен на некоторых Android/iOS устройствах. Поэтому полностью **автономный голосовой** режим пока не подтверждён. Текстовые сценарии бесплатны и не требуют облачного AI. Дополнительно потребуется проверка приватности и точных браузеров.

## Результат аудиоинвентаризации: 7 недостающих реплик

Кнопка «Слушать» активна только когда есть точная запись из `window.PandaOwnerAudio`. В нашем новом наборе такие точные записи уже есть для 你好, 我是学生, 今天星期几, 明天星期几, 这是你妈妈吗, 你有妹妹吗.

Чтобы **все диалоги панда произносила единым согласованным женским голосом**, нужна запись следующих семи реплик:

1. 你好吗？ — Nǐ hǎo ma? — Как дела?
2. 我也很好，谢谢！ — Wǒ yě hěn hǎo, xièxie! — У меня тоже всё хорошо, спасибо.
3. 你是学生吗？ — Nǐ shì xuésheng ma? — Ты студент?
4. 你是老师吗？ — Nǐ shì lǎoshī ma? — Ты учитель?
5. 你有几个？ — Nǐ yǒu jǐ ge? — Сколько у тебя?
6. 今天几月几号？ — Jīntiān jǐ yuè jǐ hào? — Какое сегодня число?
7. 今天天气怎么样？ — Jīntiān tiānqì zěnmeyàng? — Какая сегодня погода?

Важно проверить тоны новых фраз носительницей в связной речи; это только **словарный пиньинь**, в словосочетаниях с несколькими третьими тонами возможны фонетические изменения.

Не генерировать автоматически непроверенный голос и не подменять им аудио с разрешением на использование. Перед коммерческим запуском нужны записи/лицензии и проверка на Android.

## Коммерческие рамки

Код и страницы на публичном GitHub Pages не являются платёжной защитой. Для платной продажи потребуется закрытая поставка или серверная авторизация и контроль доступа; без этого любой может открыть URL напрямую.

Режим разговора является **конечным набором сценариев**, а не свободным AI-чатом. «Безлимитно» относится к количеству повторений сценариев, но панда не может понять абсолютно любой вопрос. Для расширения добавляем проверенные ветви и фразы по урокам.

## QA

`node --test tests/panda-conversation-v1.test.mjs`

Проверены 8 сценариев по 7 урокам, поддержка написания пиньиня, отказ на неверные ответы, сценарий `我很好，你呢？`, защита от переиспользования прогресса, DOM-взаимодействие. Браузерный микрофон и реальные аудиозаписи требуют отдельного **физического тестирования на телефоне**.
