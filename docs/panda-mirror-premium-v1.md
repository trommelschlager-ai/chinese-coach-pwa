# PANDA MIRROR v1 — isolated foundation
Reuses current recorded PCM pitch extraction. Two real waveform envelopes and relative pitch trajectories for a stable single syllable. No grade, no tone correctness, no inferred phonetic quality. Different registers normalized independently to median F0, time normalized per clip. Rejects short, discontinuous, multiple-region and low-clarity signals; no interpolation. Longer recordings retain waveform only. No microphone capture/playback UI, no uploads or persistence. Integration must explicitly limit pitch comparison to a known single-syllable exercise; speech recognition is not tone validation. Approved screen designs remain untouched. Android recordings and actual native speaker references still require validation. Run node --test tests/panda-mirror-premium-v1.test.mjs.
