# Panda Go Live — пакет разговоров для уроков 2–7

Подготовлены шесть разговоров в дополнение к работающему первому. Это черновики в PR #71: в опубликованный курс они не включены, поскольку ещё нет 14 полных реплик выбранного пользователем голоса.

| Урок | Сценарий | Проверка ответа | Новых MP3 |
|---|---|---|---:|
| 2 | Учитель или ученик | Две ветви: 我是老师 / 不是，我是学生 | 3 |
| 3 | Возраст | Любое число 1–100, иероглифами или цифрами, в конструкции 我…岁 | 2 |
| 4 | Дни недели | В условии диалога сегодня понедельник; несколько правильных форм ответа | 2 |
| 5 | Даты | В условии диалога сегодня 5 марта; допускаются 号 / 日 и цифры | 2 |
| 6 | Семья | Есть / нет старшего брата, в том числе с количеством | 3 |
| 7 | Погода | Два вопроса: сегодня и завтра; холодно, жарко, дождь, ясно, пасмурно | 2 |

Для календарных упражнений на экране прямо указаны условные день и дата. Это не показ реальной текущей даты. Возраст можно называть от лица персонажа; реальные персональные данные не требуются. Новые слова 几 / 岁 и необходимые подсказки доступны перед ответом. После уроков 1–2 порядок слов и грамматика проверяются по точным вариантам, без платного API.

## Общая озвучка

Единственный актуальный список для генератора — `PANDA-LIVE-BATCH-VOICE.txt`: 14 уникальных реплик с пустыми строками между ними. `PANDA-LIVE-BATCH-VOICE.json` связывает каждую фразу с уроком. Список формируется из фактических реплик и проверяется тестом, чтобы не запрашивать уже имеющиеся записи.

你好 переиспользуется из исходного пользовательского MP3. 谢谢 выделено из того же файла, интервал 5.70–6.59 с; текст отдельно подтверждён локальным Whisper как 謝謝. Традиционное написание в расшифровке обозначает то же «спасибо», не другую реплику. Акустическая оценка тонов этим не выполнялась. Для нового фрагмента измерена RMS-огибающая; происхождение, SHA-256 и границы сохранены в manifest.json. Старые голосовые курса не заменены и не удалены.

Все 14 новых фраз нужно создать тем же голосом, с той же скоростью и настройками, что в последней записи Luvvoice. Точное имя голоса в MP3 не указано. Не выбирать другой голос только потому, что он тоже женский. Можно прислать один общий MP3 с паузами между предложениями.

## Проверка и доступ

- 9 автоматических тестов PASS: первый разговор, обе роли второго, числа 1–100, условные день/дата, семья, погода сегодня/завтра, прогресс из трёх реплик, отдельное сохранение результатов и отсутствие ложного talking при недоступном звуке.
- Уроки 2–7 доступны только через явный предпросмотр `?lesson=N&preview=1`; обычный `?lesson=N` не открывает незавершённое упражнение.
- Количество индикаторов прогресса теперь соответствует числу вопросов: в погоде три реплики ученика, в остальных два.
- Поле requiresLesson сохраняет связь с уроком; вход после прохождения должен быть подключён к карте курса при включении готовой озвученной практики. Сейчас черновики не дают такой вход.
- Никакая автоматическая проверка правильности произнесённых тонов не заявляется. Физическая проверка микрофона Android остаётся отдельным шагом.

После получения общего MP3: подтвердить тексты всех 14 фраз, нарезать с запасом по краям, добавить только точные записи и их огибающие, проверить ветви и звук в браузере, затем включать готовые разговоры. До этого сохраняется статус draft и действующий первый разговор в main.
