# Native Mandarin audio correction: 日 (rì, 4th tone)

**Source:** [audio-cmn by Hugo Lopez](https://github.com/hugolpz/audio-cmn), published file `96k/hsk/cmn-日.mp3` — original human recording from the Shtooka project.

**Speaker:** Yue Tan (University of Caen / Shtooka), as attributed by the source repository.

**Licence:** Creative Commons Attribution-ShareAlike 3.0 United States (CC BY-SA 3.0 US). [Licence text](https://creativecommons.org/licenses/by-sa/3.0/us/).

**Modification:** The original MP3 is included without altering its speed, pitch, or waveform. The surrounding user interface provides attribution and separately accelerates some synthetic female clips, not this recording.

**Why:** The Kokoro synthetic rendition of 日 was reported to be unnatural. The native sample replaces only this one character. The rest of HSK 1 keeps the approved female/male Kokoro voice pair.

**Transparency:** The word is written 日 and read *rì*, fourth tone. Native-source attribution does not replace individual audio listening tests.
