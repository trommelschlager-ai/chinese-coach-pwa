# Panda AI HSK 2 · «Мой день» — единый голос LuvVoice

**Состояние:** 14 MP3 подготовлены из записи пользователя от 20 ноября 2026; двоичные файлы должны быть загружены в эту папку. До загрузки приложение не объявляет пакет установленным.

## Установка
1. Распаковать архив `Panda_Go_HSK2_My_Day_LuvVoice_14_MP3.zip`.
2. Загрузить все `day01.mp3` … `day14.mp3` и `manifest.json` непосредственно в эту папку GitHub: `assets/panda-hsk2-my-day-voice-20261120/` (не в подпапку).
3. Проверить GitHub Pages и открыть `panda-voice-pilot.html?scenario=hsk2-my-day&from=hsk2-lesson1`.
4. Убедиться, что весь рассказ, вопросы и повторение используют единый голос, без TTS Android. Проверить микрофон Android и остановку/повтор аудио.

Страница ищет `manifest.json`, проверяет доступность всех 14 MP3, только после этого активирует новую озвучку. При отсутствии пакета остаются старые утверждённые LuvVoice MP3, а отсутствующие фразы отображаются текстом. **Нельзя считать страницу полностью озвученной до загрузки бинарных файлов.**
