# Game Practice — recorded Mandarin audio (v90)

The single-speaker word audio is from **Yue Tan** (Shtooka / Collection Audio Libre de Mots Chinois), packaged by **Hugo Lopez** as the [audio-cmn project](https://github.com/hugolpz/audio-cmn/tree/master/64k/hsk).

**License:** [Creative Commons Attribution–ShareAlike 3.0 United States (CC BY-SA 3.0 US)](https://creativecommons.org/licenses/by-sa/3.0/us/).

New files in this update: `cmn-在.mp3`, `cmn-几.mp3`, `cmn-点.mp3`, `cmn-很.mp3`, `cmn-多.mp3`, `cmn-大.mp3`, `cmn-不.mp3`, `cmn-中.mp3`, `cmn-国.mp3`, `cmn-小.mp3`. Source files: `64k/hsk/cmn-{hanzi}.mp3`. Audio bytes preserved without alteration.

In the "Собери фразу" exercise, `中国人` is assembled from recorded `中`, `国`, `人`; `二十五` from recorded `二`, `十`, `五`. These are separate native-speaker clips, not a continuous full-word recording. `小明` remains unvoiced until a verified same-speaker clip can be provided; no robotic fallback is used.

The dialogue audio in "Слушай и выбирай" is not changed. The remaining images and code of the application have separate provenance/licenses.
