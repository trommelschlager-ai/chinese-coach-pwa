## Загрузка

1. Откройте ветку `audio/panda-voice-v411-staging`.
2. Перейдите в `assets/panda-voice-clips-v411/`.
3. Нажмите **Add file → Upload files** и выберите одновременно **10 распакованных MP3** (не ZIP).
4. Commit changes **в эту ветку**.
5. Проверьте обязательный тест `voice-v411-asset-verification` в PR #112 и остальные CI-проверки. Не объединяйте с `main`, пока не пройдут тесты и ручная проверка Android.

Код индекса готов в `assets/panda-voice-v411.mjs`, подключение — в `assets/panda-live-audio.mjs`.
Контрольные суммы сверяются в `tests/panda-voice-v411-assets.test.mjs`.

**Важно:** техническая целостность файлов подтверждена локально, но китайское произношение и все тоны ещё не прошли полную акустическую проверку. Проверки микрофона Android и воспроизведения на реальном телефоне также ещё не выполнены.
