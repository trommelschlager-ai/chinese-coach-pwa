# Panda Go v237 — фактически внесённые исправления

Исправляются действующие уроки 1–7. Учебные данные и ключи прогресса сохранены.

- Единый расчёт видимой области через visualViewport и внутреннюю прокрутку; нижние кнопки не меньше 56 CSS px, отступ снизу не меньше 20 px и safe-area. Отдельный фиксированный футер урока 6 удалён.
- Урок 3: вместо неверного изображения интерфейса используется существующая фирменная панда из утверждённого комплекта v233; миниатюра бренда тоже исправлена.
- 70 оригинальных записей носительницы обработаны мягким шумоподавлением и нормализацией; исходники не изменены. Во всех уроках они имеют приоритет.
- 168 существующих резервных источников обработаны отдельно. При отсутствии оригинала показывается явное указание временного источника. Новый синтез и клонирование голоса не применялись.
- Урок 1: удалены программное замедление и обрезка окончаний.
- Запись ученика сохраняется при перемещении между экранами в уроках 1, 2, 4–7; усиление ограничено с учётом уровня тихих участков. В уроке 3 записи микрофона нет.
- Три распознанных повтора в уроке 2 сохранены. Доступен переход в словарь без распознавания, без фиктивного зачёта повторов.
- Уточнено объяснение 很 перед прилагательным в описании погоды.

## Автоматические проверки

- npm run check и npm run check:release — существующие проверки курса, учебных заданий и прогресса.
- verify-panda-go-approved-v231 — полные сценарии уроков 6 и 7.
- verify-hsk1-fifth-v227 — полный сценарий урока 5.
- verify-lesson-viewport-v237 — 112 сценариев изменения видимой области для ширин 320 / 360 / 393 / 430 px.
- verify-mic-retention-v237 — запись, переход между экранами, возврат и воспроизведение в 6 уроках с имитацией микрофона.
- audit-active-audio-v237 — восстановление 96 экранов; 202 аудиокнопки, 126 разных источников; не подтверждает качество произношения.

Некоторые старые тесты фиксировали прежние номера ресурсов, фиксированный футер урока 6, скорость 0.8x и ограничение 141 файла оболочки. Эти ожидания обновлены под новые требования. Проверки учебных заданий и прогресса сохранены. Новая оболочка содержит 145 ресурсов; медиа остаются дополнительной загрузкой.

## Реестры и границы проверки

active-audio-registry.csv/json — кнопки на восстановленных экранах с измеренными параметрами.
full-route-inventory.csv/json — 262 доступных маршрута, включая динамические числа и варианты повторения. Это расширенная инвентаризация, а не утверждение, что каждый вариант был прослушан.
needs-native-recording.md/json — 154 варианта без соответствующей записи утверждённой носительницы в подключённых пакетах. Числа 0–100 перечислены целиком, поскольку компиляция из фрагментов другого диктора не заменяет цельную запись.

LUFS измеряются автоматически. Для клипов короче 400 мс интегральный LUFS может отсутствовать при наличии звука; это отмечено в реестре. Пиньинь в расширенном реестре сформирован по словарю, с yì bǎi для 一百; фразовые изменения тонов требуют отдельной проверки на слух.

**Не подтверждены:** правильность произношения и тонов каждой записи, субъективное отсутствие шума/щелчков, микрофон и системные панели на физическом Android. Существование файла и нормализация не считаются такой проверкой.

Публикация и браузерная проверка будут подтверждены в browser-results.json после выполнения. Задача не объявляется полностью закрытой до оставшихся проверок и замены недостающих оригинальных записей.
