# Panda Street R4 · эксперимент

Исходники: day.webp и night.webp из main, оба 693×1444. Из PR #201 изучены отчёты ART-REVIEW и R3-MOTION-REVIEW и координаты маски R2. Для R4 маска размечена заново по увеличенному фрагменту исходника с включением кисти, часов и предплечья.

Для каждой темы собраны пять RGBA-слоёв и шесть PNG-поз. Первый и последний PNG совпадают с декодированным WebP попиксельно. Ни один пиксель вне области руки и её стыка с одеждой не меняется. Для каждой движущейся позиции полностью непрозрачная часть слоя кулака сверена с исходником после целочисленного сдвига. Металл и отверстия сохраняют исходные пиксели. Кисть и предплечье движутся вместе. Максимум — 8 пикселей вверх и 2 вправо, с короткой паузой. MP4 состоит из двух жестов по 1,5 секунды, H.264/yuv420p, 30 кадров/с. Справа добавлен один столбец для кодека, масштаб исходного растра не меняется.

В кадрах используется вручную обведённый контур и клонированная из соседних пикселей ткань. Это этап проверки композиции. Скрытая одежда не дорисована вручную, при максимальном подъёме на увеличении заметен переход под манжетой и у складки возле часов. Позы заданы отдельными положениями слоёв с промежуточными позициями, полноценной ручной прорисовки движения предплечья и рукава пока нет. Воспроизведение на реальном Android не проверено.

Для воспроизведения сборки из корня репозитория: `python experiments/panda-street-r4/build.py` (Pillow, NumPy, FFmpeg). Затем откройте `index.html` рядом с MP4. Автономный HTML из комплекта содержит MP4 внутри.

Статус: требует дальнейшей художественной доработки. Для интеграции не утверждён.
