# Panda Go HSK 1 — дикторский лист для 56 недостающих фраз

Проверено: 124 позиций, 59 точных оригиналов Юэ Тань, 65 отсутствуют. После объединения пунктуационных вариантов остается **56 уникальных фраз**, которые нужно записать настоящей носительницей китайского. Источник: [Yue Tan / Shtooka / Hugo Lopez](https://github.com/hugolpz/audio-cmn), лицензия [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/).

**Статус:** подготовка аудио. Ни один из этих 56 клипов пока не записан; это не разрешение автоматически заменять живой голос синтетическим или клонировать Юэ Тань.

Для записи: путунхуа, спокойный нормальный темп, без лишнего гласного или 'й' в конце, без реверберации, без ускорения, с корректными тонами и нейтральными окончаниями. Каждый текст записывать как единую естественную фразу, а не склеивать из одиночных слогов. Проверка носителем перед публикацией обязательна. Пиньинь ниже взят из текущего манифеста и требует независимой проверки в контексте.

## Приёмка и ограничения

1. Получить 56 отдельных живых запись/дублей, сопоставить с 65 позициями по нормализованной форме без изменения значимых слов. Вопросительные фразы отдельно проверить на интонацию.
2. Проверить сандхи, тоны, нейтральные слоги, правильное 'r' в 日, финали, ясную дикцию, естественную скорость, целостность звука без пропусков.
3. Сохранить аутентичность 59 имеющихся образцов Юэ Тань; не приписывать другой дикторше авторство Юэ Тань. Для новых записей требуется лицензия/договор о праве коммерческого использования и размещения в Panda Go.
4. Только после полного набора аудио и проверки на Android рассматривать замену производственной аудиокарты. Мужские 14 реплик и дизайн не менять.

**Важно:** Чтобы звучал буквально один и тот же женский голос во всех 124 позициях, потребуется записать *все 124 фразы одной новой дикторшей* или заключить договор с самой Юэ Тань. Добавление 56 фраз другим человеком закрывает пробелы в звуке, но не делает голос единым.
